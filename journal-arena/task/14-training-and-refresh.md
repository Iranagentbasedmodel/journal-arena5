# task/14-training-and-refresh.md — آموزش مازاد اجباری هر گروه + بروزرسانی دانش
### هیچ ایجنتی پیش از تکمیل برنامهٔ آموزشی گروهش وارد موج ارزیابی نمی‌شود (قانون Tier-0).
### خروجی آموزش = یک یادداشت ≤۱۰ خطی در `work/training/<gid>.md` با منابع خوانده‌شده.

## معیارهای جدیدی که به ارزیابی اضافه شدند (از جست‌وجوی ۲۰۲۶)
- **نشان‌های ACM برای artifact**: Available / Functional (documented, consistent,
  complete, exercisable) / Reusable / Results-Reproduced در برابر Results-Replicated؛
  مخزن آرشیوی با DOI (GitHub شخصی قابل قبول نیست)؛ license file؛ proxy برای دادهٔ
  اختصاصی؛ قاعدهٔ اجراهای >۲۴ ساعت (پیش‌محاسبه + weights)؛ اسکریپت timing با گزارش
  سخت‌افزار. → به E5 اضافه شد.
- **تاکسونومی هشت‌گانهٔ نشتی (Kapoor & Narayanan 2023, Patterns)** + الزام
  «model info sheets» استاندارد. → به E4/E5 اضافه شد (مقالهٔ هدف خودش
  leakage-audited است؛ ممیزی باید با تاکسونومی مرجع سنجیده شود).
- **ده خطای آماری رایج داوری** (eLife/PMC): تفسیر p به‌عنوان احتمال فرض صفر، نبود
  اثر اندازه، تعدد بدون اصلاح، تفسیر بیش از حد نتیجهٔ غیرمعنادار، همبستگی↔علیت،
  توان پس‌آزمون (ممنوع — فاصلهٔ اطمینان گزارش شود)، df ناقص، p=.000، عبارات مبهم
  نتایج، نادیده‌گرفتن خوشه‌بندی/تودرتویی. → چک‌لیست E4.
- **نرم LBNL «Good practices for documenting AI-based studies on energy and
  buildings» (۲۰۲۶)**: Datasheets for Datasets؛ مستندسازی پیش‌پردازش (پاکسازی،
  outliers، missing/imputation، نرمال‌سازی، feature engineering)؛ تقسیم زمانی برای
  سری زمانی؛ مستندسازی کامل هایپرپارامتر (مقدار+منبع+فضای جست‌وجو+روش)؛ توجیه
  الگوریتم؛ baseline+CV+error analysis؛ گزارش seed (نبودش = تفاوت دو برابری نتایج)؛
  ارزیابی تعمیم روی ساختمان/نمونهٔ ندیده؛ خطای مدل به تفکیک فصل/اقلیم/اکوپانسی.
  → استاندارد میدان برای E4/E5/E6.
- **الگوهای desk-reject اختصاصی ENB** (نرخ ۳۰–۴۰٪): غربال AE با یک سؤال —
  «آیا پیامد انرژی ساختمان در برابر یک baseline تعریف‌شده کمّی شده؟»؛ سه الگوی
  پرتکرار: (۱) نبود مشخصات weather file یا ناسازگاری اقلیمی آن؛ (۲) مطالعهٔ
  تک‌نمونه با ادعای تعمیم بدون آنالیز حساسیت (تیپ/اکوپانسی/اقلیم)؛ (۳) نقص
  declarations. داوران به مدل شبیه‌سازی، فرضیات رفتار occupants و ابزار
  اندازه‌گیری نفوذ می‌کنند. → به E7 اضافه شد.
- **آمار نمونهٔ پیچیده (RECS)**: وزن‌های نمونه، طبقه‌بندی، design effect،
  واریانس Taylor-linearization؛ هر عدد ملی بدون وزن = finding major در E4.
- **اعتبارسنجی تفسيرپذیری**: ثبات/سازگاری توضیحات، مقایسه‌پذیری بین وظایف،
  هشدار SHAP/LIME (همبستگی ویژگی‌ها) → E4 (چون مقاله interpretable-ML محور دارد).

## قابلیت‌های مازاد شورای نخبگان (الزامی برای عضویت)
1. **سنجه‌شناسی کتاب‌سنجی**: مقایسهٔ مسیر استنادی مورد انتظار با مقالات مشابه ENB؛
   آگاهی از topic-burstiness و FWCI.
2. **کالیبراسیون تصمیم**: مطالعهٔ سالانهٔ متاریوهای منتشرشده + آمارهای پذیرش؛
   پیش‌بینی desk-reject با الگوهای E7.
3. **تئوری تصمیم تحت عدم‌قطعیت**: رأی وزنی (body=1/abstract=0.5)، داوری تنازع،
   سبد ریسک P0/P1/P2 با ارزش انتظاری.
4. **سنتز میان‌حوزه‌ای**: انرژی‌آمار ↔ روش‌شناسی ML ↔ فیزیک ساختمان؛ هیچ عضوی
   تک‌حوزه‌ای رأی نهایی نمی‌دهد.

## قابلیت‌های مازاد کدنویسان نخبه
1. بسته‌بندی artifact طبق ACM/SIGIR: lockfile + container **image** (نه فقط Dockerfile)
   + نوت‌بوک زنده + بستهٔ نصبی.
2. بهداشت عددی: seed گزارش‌شده، قطعیت floating-point/BLAS، golden/regression test،
   property-based test.
3. پروفایل و بودجهٔ منابع: RAM≤8GB، بدون GPU، ≤۳۰ دقیقه؛ قاعدهٔ >۲۴ ساعت =
   artifact پیش‌محاسبه‌شده.
4. انطباع امنیتی/مجوز: license scan وابستگی‌ها، secret scan، SBOM.
5. مستندسازی در سطح «documented» بدج functional: README نصب+اجرا، لاگ موفقیت‌ها و
   شکست‌ها، دادهٔ نمونه/proxy.
